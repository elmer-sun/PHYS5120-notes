# PHYS5120 计算物理

PHYS5120（Computational Physics）课程的中文讲义，以适合自学的方式组织内容，注重物理概念、公式的逐步推导与计算方法之间的联系。

内容涵盖分子动力学与 Monte Carlo、电子结构与密度泛函理论，以及周期固体、晶格振动和第一性原理分子动力学。

[阅读讲义 PDF](计算物理.pdf) · [LaTeX 源码入口](main.tex)
